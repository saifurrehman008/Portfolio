# Saif Grafix Portfolio

A responsive portfolio website for Saif-ur-Rehman Soomro, showcasing graphic design services and selected work.

## Run locally

Open `index.html` in a browser, or use a local static server such as VS Code Live Server.

## Project files

- `index.html` — page content and portfolio gallery
- `style.css` — site styling
- `script.js` — gallery filters, page effects, and contact form behavior
- `images/` — profile photo, portfolio work, business cards, and certificate

## Contact form

The form opens the visitor's email app with the message addressed to `saifiubian2k25@gmail.com`. The visitor sends it from their own email app. The website does not save submissions or use a database.
